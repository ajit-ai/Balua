Development and Contributing

Branches: main (production) ← develop (integration) ← phase/*. Never commit to main; merge --no-ff, then tag. Rules: CONTRIBUTING.md, GIT_WORKFLOW.md.

CI (.github/workflows/ci.yml)

build (windows): workspace build, lexer/parser/semantic/safety suites, execution suite, --emit-mir and -o smokes. blpkg: build + help smoke. docs (ubuntu): sphinx-build -b html -W (warnings fail).

Local verification

cargo build --workspace
cargo test -p baluac --test lexer_tests --test parser_tests --test semantic_tests --test safety_tests
cargo test -p baluac --test execution
cargo test -p blpkg

Local docs

Open docs/index.html (file:// works). Sphinx build (output git-ignored): pip install -r docs/requirements.txt && sphinx-build -b html -W docs docs/_build/html. The Pages workflow deploys to GitHub Pages on main pushes (enable under Settings → Pages → Source: GitHub Actions).
