Heterogeneous Computing

Established material only — no accelerator execution exists.

Targets (spec)

CPU x86_64/aarch64/riscv64/arm-none-eabi; GPU SM70–90 PTX + SPIR-V 1.6; NPU HTP/ANE/Intel/Samsung/MediaTek; FPGA UltraScale+/Versal/Agilex; QPU IBM/Azure/IonQ/Rigetti. Manifest [hardware] in Balua.toml:12. Only the C-compatible CPU path executes.

Backend status

Cranelift: runnable host objects. LLVM/PTX/SPIR-V/HLS/QASM/MLIR: header/template text. baluald fat-binary linker: print-only stub. @hw:: regions describe intent; only CPU regions run.

Simulation fallback

std/hal/*.bl functions return dummies (core_count() -> 1). The compiler never reads std/ — documentation-grade text, not linked code.

Measured example status

--emit-mir exit codes: 01_hello_hardware, 05_fpga_fir_filter, 06_quantum_grover clean; other 18 of 21 report diagnostics (e.g. 03_gpu needs slice types/+= — real gaps, out of scope). Only hello.bl linked+executed.
