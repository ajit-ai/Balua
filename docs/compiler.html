Balua Compiler

Rust (baluac_lib + balua/baluac bins). Entry main.rs:65. Any Error diagnostic blocks -o.

Stages

  • Lexer (lexer.rs): UTF-8, 47 keywords, @hw:: directives, #[...] annotations, spans.
  • Parser (parser.rs): recursive descent; top-level module blocks; fn/let/const/if/match/for/while/loop/return/break/continue/spawn/chan/select/unsafe/extern. No precedence table, no paren grouping.
  • AST (ast.rs): 14 item variants; FnDecl carries generics/visibility/tiers/raw attrs. Most expr spans are defaults.
  • Semantic (semantic.rs): HM-style unify + borrow/move + hw validation → E_TYPE_MISMATCH E_USE_AFTER_MOVE E_BORROW_CONFLICT E_HW_*. Imports unresolved.
  • MIR (mir.rs): SSA blocks; real FnDecl lowering; kernels → intrinsic+trap; strings → null; casts pass through; calls need Ident.
  • Backends: Cranelift real (i32 objects + host link). LLVM/PTX/SPIR-V/HLS/QASM/MLIR are template text. baluald unused stub.

CLI

balua [files...] [--emit-mir] [--emit-llvm] [--emit-clif] [--backend HW]
  [--cpu-backend llvm|cranelift] [--release] [-o EXE] [--keep-object]
  [--target TRIPLE] [--json-diagnostics] [--safety-profile P]
  [--safety-stack-limit N] [--verbose]

main() returning i32 becomes the exit code. No optimization passes exist (--release only selects Cranelift speed mode).
