Balua Principles

Source: spec/BLRS-v1.0.md:10, README.md:7. Motto: One Language. Every Silicon.

1. Zero-cost abstractions

High-level Tensor stream spawn/chan compile to optimal code. MIR inlining + Pure elision, LLVM O3+LTO/PGO/BOLT.

2. Hardware-first

Hardware is syntax: @hw::, kernel/circuit/tensor fn, qubit v512 Tensor. Per-region backends + baluald fat binary.

3. Safety without GC

Single owner, move, borrow, lifetimes, Send/Sync. E_USE_AFTER_MOVE E_BORROW_CONFLICT E_TYPE_MISMATCH. No GC, no_std ready.

4. Unified toolchain

One balua driver + blpkg + fmt/lsp/dbg/prof/doc/test/bindgen. JSON diagnostics, events, profile JSON.

5. Determinism

Reproducible builds, fuzzed frontend, #[requires]/[ensures] → Frama-C/CBMC, WCET/stack proofs.

6. Interoperability

C ABI stable, extern for C/C++/Rust/CUDA/OpenCL, Python, VHDL/Verilog, WASM, .blh bindgen.

7. Certifiability

--safety-profile AUTOSAR/DO-178C/IEC61508, MISRA, #[max_stack]/[wcet_cycles]/[interrupt_handler], SBOM + provenance.

8. Simulation-first portability

HAL sim fallbacks (#[test(sim=true)]), cross-arch/back-end/OS.

9. Self-hostability

Rust now, Balua within 3 majors. selfhost/lexer.bl parser.bl done; ast/mir/semantic next. Parallel/incremental builds.

10. Open governance

MIT/Apache-2.0, Design Authority, GIT_WORKFLOW.md:3 (main←develop←phase/*), per-phase tags.
