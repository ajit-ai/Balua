Balua Architecture

.bl → Lexer → Parser → AST → Semantic(+TypeTable) → MIR → Backend → host link → exe

Driver main.rs:65 orchestrates inline and gates -o on zero errors. Details: Compiler, Safety, phase plan.

Load-bearing contracts

  1. Spans mostly default — type table is coverage-grade.
  2. MIR registers/params are strings; Phi unused by backend.
  3. Backend::lower -> String lets template backends pass with comments.
  4. Two linkers: real object_emit vs unused baluald — one must go.
  5. Top-level module blocks parse; nested rejected; use unresolved; std/ never read.
  6. No runtime — standalone exes, exit-code I/O; strings/collections unrepresented.
  7. Safety is MIR walkers over CPU functions; tiers are labels; HW regions skipped.
  8. Balua.toml read by blpkg only.

Decisions on record

Hardware-first syntax, ownership without GC, HM-style inference, C-ABI intent, sim-fallback HAL, Cranelift-first on 4GB budget, develop → main --no-ff. Phases: Roadmap.
