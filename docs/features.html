Balua Features

Sources: spec/BLRS-v1.0.md:1, spec/grammar/balua.ebnf:1, spec/abi/balua-abi-v1.md:1, README.md:52, crates/baluac/src/main.rs:11, crates/baluac/src/backend/mod.rs:21.

1. Language core

  • Statically-typed compiled system language. Files: .bl, .blh, Balua.toml, balua.exe/baluac, blpkg/BPM.exe, REPL balua.
  • Lexical: UTF-8 Unicode, @hw:: directives, #[...] / #pragma. ~40 keywords: fn let mut const struct enum trait impl mod module use if else for while loop match return break continue unsafe async await spawn chan select extern type where pub self Self super crate box move in as is kernel circuit tensor qubit true false.
  • Control flow: let if/else for/while/loop match return spawn chan select! unsafe. Functions: fn async fn extern kernel fn circuit fn tensor fn, closures borrow/move. Effects: Pure | IO | HardwareIO | Unsafe.
  • Modules: module, use hw::cuda::Grid;, Balua.toml:12 with [hardware] cpu/gpu/npu/fpga/quantum.

2. Type system

  • Primitives i8..i128 u8..u128 f16/f32/f64/f128 fp16/bf16/tf32 bool char qubit[N] *mut/*const/&/&mut v128/v256/v512; struct/enum/trait, Tensor<T,Shape>, stream<T>, GpuTensor, FpgaBuf, const generics (dimension mismatch = compile error).
  • Semantic: HM inference (types/inference.rs:1) + borrow (types/borrow_checker.rs:1) + lifetimes (types/lifetime.rs:1) + hw types + effects. Errors E_TYPE_MISMATCH E_BORROW_CONFLICT E_USE_AFTER_MOVE.

3. Memory & ownership

  • Single owner, move, box<T>::new, 'a, x.move_to_device() invalidates x, cross-device lifetimes.

4. Compiler pipeline

  • Lexer (lexer.rs:1) → Parser (parser.rs:1, ast.rs:1) → Semantic (semantic.rs:1) → MIR SSA (mir.rs:1) → Backends → baluald (linker/baluald.rs:1).
  • CLI: --emit-llvm --emit-mir --emit-clif --target --backend --cpu-backend llvm|cranelift -o --keep-object --json-diagnostics --safety-profile --verbose.

5. Backends

  • select_backend(hw) (backend/mod.rs:21): LLVM (x86_64/aarch64/riscv64/arm-none-eabi, LTO/PGO/BOLT), Cranelift + object_emit.rs:1 build_executable → linked .exe, PTX SM70-90, SPIR-V 1.6, HLS Vitis + Tcl/xdc, OpenQASM3/Q#, MLIR balua dialect. Fat binary ELF+CUBIN+SPIR-V+bitstream+QASM + __balua_hw_manifest.
  • ABI: C stable, _Bl<N>... mangling, #[export_c], PTX .entry, SPIR-V OpEntryPoint, HLS m_axi/axis, ONNX NCHW, QASM measure.

6. Hardware abstractions

  • @hw::gpu(backend=cuda,sm=90) @hw::fpga(target=ultrascale_plus) @hw::npu(backend=onnx) @hw::quantum(backend=openqasm3) @hw::cpu @hw::embedded. Per-region codegen then stitch.

7. Concurrency

  • spawn chan<T> select! Future async/await Mutex/RwLock/Condvar, Send/Sync inferred. Example examples/01b_parallelism.bl:1.

8. Standard library

  • std/: core mem alloc collections string io fs net thread sync atomic time math simd tensor hal ffi panic test fmt iter future log. no_std compatible. HAL std/hal/ cpu/gpu/npu/fpga/quantum/embedded/memory with sim fallback #[test(sim=true)].

9. FFI

  • extern "C/C++/rust/cuda/opencl", Python, VHDL/Verilog, WASM, balua-bindgen → .blh.

10. Safety

  • --safety-profile=AUTOSAR_CPP14|DO-178C|IEC61508, #[max_stack] #[wcet_cycles] #[interrupt_handler] #[requires]/[ensures] #![no_panic] #[sandbox], MISRA/WCET/stack/Frama-C/CBMC, Bom.toml SBOM.

11. Package manager

  • new/build/run/test/bench/add/publish/doc/fmt/lint/cross, PubGrub resolver, builder, registry (blpkg.io), checksums/lockfile/provenance. Targets gpu:cuda:sm90 fpga:xilinx:ultrascale_plus quantum:ibm:fake_manila arm-none-eabi.
