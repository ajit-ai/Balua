Runtime and Packages

No Balua runtime exists. Executables are standalone; main() -> i32 becomes the exit code. Strings lower to null, concurrency has no lowering, HAL is unlinked text.

Package manager (blpkg/BPM)

  • new — scaffolds Balua.toml + src/main.bl (real).
  • build — parses manifest, compiles src/main.bl via baluac lib → target/debug/<name>.exe (real, local-only; non-CPU targets note post-GA).
  • run — builds then executes, reports exit (real).
  • test — builds then executes, reports test(sim) (minimal; no Balua harness yet).
  • add name[@req] — semver validation, local-only (real).
  • publish — explicit post-GA error (no fake success).
  • bench/doc/fmt/lint/cross — prints (post-GA). bom — CycloneDX-style TOML, full variant with provenance fields.
blpkg new demo && blpkg build && blpkg run && blpkg test
